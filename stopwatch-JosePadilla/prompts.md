quiero que crees un cronómetro y una cuenta regresiva usando HTML, CSS y JavaScript, basándote en un archivo index.html y un script.js



La idea es que se vea similar al estilo del sitio https://www.online-stopwatch.com/ y como la imagen adjunta (solo como referencia de diseño).



Quiero que tenga:



\* Un cronómetro que pueda iniciar, pausar, reanudar y reiniciar.

\* Una cuenta regresiva configurable (el usuario puede poner los minutos y segundos antes de empezar).

\* Una opción para cambiar entre el cronómetro y la cuenta regresiva (por ejemplo, con botones o pestañas).

\* Un sonido o alerta cuando la cuenta regresiva llegue a 0.

\* Animaciones suaves en los números o botones (por ejemplo, un efecto de fade o scale).

\* Que el diseño sea limpio, centrado y con botones grandes y claros, con tonos pasteles y una interfaz bien orientada a la experiencia del usuario.

\* Todo el comportamiento debe ir en el script.js, el HTML solo debe tener la estructura básica.

\* No se pueden usar librerías externas, solo JavaScript puro.

\* El código debe estar bien comentado y ordenado para entender la lógica fácilmente.



Entrégame el código completo de ambos archivos (index.html y script.js), bien formateado y con una breve explicación de cómo funciona todo.
