# Carpeta de Recursos (res/)

Esta carpeta está destinada a contener recursos adicionales para la aplicación:

- **Iconos**: Favicon, iconos de aplicación PWA
- **Imágenes**: Assets visuales, logos, ilustraciones
- **Fuentes**: Tipografías personalizadas (si se añaden)
- **Audio**: Sonidos personalizados para notificaciones
- **Manifests**: Archivos manifest.json para PWA

## Uso Futuro

Cuando añadas recursos a esta carpeta, recuerda:

1. **Optimización**: Comprime imágenes para mejor rendimiento
2. **Nomenclatura**: Usa nombres descriptivos y consistentes
3. **Organización**: Considera subcarpetas (icons/, images/, audio/, etc.)
4. **Referencias**: Actualiza las rutas en HTML/CSS/JS según sea necesario

## Iconos Recomendados (PWA)

Para convertir esta app en PWA, considera añadir:
- icon-192x192.png
- icon-512x512.png
- apple-touch-icon.png
- favicon.ico
- manifest.json
