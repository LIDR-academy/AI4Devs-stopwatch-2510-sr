Documentación del Componente Web Timer

Este documento explica cómo incrustar y configurar el componente Web Timer en cualquier otra página web.

Uso Básico (Iframe)

La forma más sencilla de usar el componente es a través de una etiqueta <iframe>. Apunta el atributo src a la URL donde tengas alojado el index.html. 

<!-- Ajusta 'width' y 'height' según tus necesidades -->
<iframe 
    src="URL_DEL_COMPONENTE/index.html" 
    width="430" 
    height="280" 
    frameborder="0"
    title="Web Timer Component">
</iframe>

Modos de Visualización

El componente puede cargarse en tres modos diferentes utilizando parámetros en la URL (query strings).

1. Modo "Ambos" (por defecto)

Muestra ambas funcionalidades (Stopwatch y Countdown) con pestañas para que el usuario elija.

  • Parámetro: Ninguno, o ?mode=both
  • Ejemplo de Iframe:
<iframe src="URL_DEL_COMPONENTE/index.html?mode=both"></iframe>

2. Modo "Stopwatch" (Solo cronómetro)

Muestra únicamente el cronómetro, sin pestañas ni la opción de cuenta atrás.

  • Parámetro: ?mode=stopwatch
  • Ejemplo de Iframe:
<iframe src="URL_DEL_COMPONENTE/index.html?mode=stopwatch"></iframe>

3. Modo "Countdown" (Solo cuenta atrás)

Muestra únicamente la cuenta atrás, sin pestañas ni el cronómetro.

  • Parámetro: ?mode=countdown
  • Ejemplo de Iframe:
<iframe src="URL_DEL_COMPONENTE/index.html?mode=countdown"></iframe>
